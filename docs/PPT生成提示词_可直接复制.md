## 项目背景

项目名称：AI药管家 —— 智能老人用药管理系统
这是一个面向老年人的智能用药管理平台，采用前后端分离架构（React 18 + Spring Boot + MySQL），整合 DeepSeek 大模型、百度 OCR、百度 TTS 三大 AI 能力，实现"识药-管药-提醒-监护-咨询"全流程闭环。

核心技术亮点：
- 渐进式四阶段提醒（提前15分钟→到时→超时→通知家属），颜色从蓝到深红递进
- 双保险漏服监控（渐进式提醒状态机 + 绝对时间扫描，独立运行协同触发）
- AI 降级容错（API异常时本地规则降级，核心功能仍可用）
- 7维度药品冲突检测（结合老人健康档案，13类冲突场景秒级响应）
- 拍照识药（百度OCR高精度版 + DeepSeek大模型提取药品名，自动匹配94种药品库）

项目成果数据：
- 94种药品基础库，覆盖18类药品
- 80个 REST API 端点
- 19张业务表，20个外键，9个唯一约束，30+索引
- 12个控制器，22个服务实现类，13个配置类
- 4个定时任务（自动过期药品、生成用药计划、生成科普、渐进式提醒扫描）
- 老人端7个Tab+19个业务组件，家属端3个Tab+6个业务组件
- 第一阶段5项量化目标全部达成：用药依从性85%+、冲突检测<1秒、18px基准字号、漏服10分钟通知、可用性99%

## PPT 设计要求

### 整体风格
- 视觉风格：医疗专业 + 暖意，白底为主，专业可信又不冷漠
- 主色：科技蓝 #3A7BC8
- 辅色：薄荷绿 #4CAF50（成功/健康）
- 暖色：杏色 #F5C6A5（点缀/温度感）
- 警示色：红色 #E74C3C（痛点/危险）
- 每页主色不超过3种，避免渐变背景填充整页
- 标题用思源黑体Bold 36-44px，正文18-20px，数字用DIN字体60-96px
- 不对称布局（左标题+右内容），留白充足，避免居中堆砌
- 动画仅用淡入+上移和数字递增，禁用旋转/弹跳/立方体

### 时长与页数
- 总时长5-8分钟，控制在16页以内
- 每页文字不超过50字，靠口播补充
- 包含：开场引言、主体内容（4个模块）、数据支撑、总结与展望

### 加分视觉要素（必须包含）
1. 渐进式提醒色阶条：用蓝→橙→红→深红四色横向色阶，直观展示提醒递进
2. 数据仪表盘卡片：3-4个数字卡并排，大数字+小标签+图标，数字用CountUp递增动画
3. 四层架构分层图：表现层/业务层/数据层/外部服务，色块分层
4. 药品冲突关系图：节点连线图，标红冲突对
