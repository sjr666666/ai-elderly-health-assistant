## 提交信息规范

### 格式
```
<类型>: <简短描述>

[详细说明（可选）]
```

### 类型说明
- **feat**: 新增功能
- **fix**: 修复 bug
- **docs**: 文档更新
- **style**: 代码格式调整（不影响功能）
- **refactor**: 代码重构
- **test**: 测试相关
- **chore**: 构建/工具类任务

### 示例
```
feat: 添加用户登录功能

- 实现用户名密码验证
- 添加登录状态管理
```

### 注意
- 标题不超过 50 字符
- 使用中文描述
- 动词开头，简洁明了
