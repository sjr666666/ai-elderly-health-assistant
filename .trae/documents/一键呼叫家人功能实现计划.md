# 一键呼叫家人功能实现计划

## 一、功能概述

**目标：** 实现紧急情况下老人一键呼叫家人的功能，通过 `tel:` 协议调起手机原生拨号界面。

**当前状态：**
- 前端已有"一键呼叫家人"按钮（EmergencyAssistant.js），使用 `window.location.href = tel:${phone}` 调起拨号
- EmergencyContact 实体类已存在，对应数据库表 `emergency_contact`
- **缺失：** 后端 CRUD API 用于持久化紧急联系人数据

---

## 二、需要创建的后端文件

### 2.1 Mapper 层
**文件：** `com.example.backend.mapper.EmergencyContactMapper.java`
- 继承 `BaseMapper<EmergencyContact>`
- 提供按 `elderId` 查询联系人列表的方法

### 2.2 Service 层
**文件：** `com.example.backend.service.EmergencyContactService.java` (接口)
**文件：** `com.example.backend.service.impl.EmergencyContactServiceImpl.java` (实现)
- `getContactsByElderId(Long elderId)` - 获取老人的所有紧急联系人

- `updateContact(EmergencyContact contact)` - 更新紧急联系人
- `deleteContact(Long id)` - 删除紧急联系人
- `getPrimaryContact(Long elderId)` - 获取主要联系人

### 2.3 Controller 层
**文件：** `com.example.backend.controller.EmergencyContactController.java`
- `GET /api/emergency/contacts?elderId={elderId}` - 获取紧急联系人列表
- `POST /api/emergency/contacts` - 添加紧急联系人
- `PUT /api/emergency/contacts/{id}` - 更新紧急联系人
- `DELETE /api/emergency/contacts/{id}` - 删除紧急联系人

## 四、数据库表结构

已存在于 `init_database.sql`：

```sql
CREATE TABLE `emergency_contact` (
  `id` bigint NOT NULL AUTO_INCREMENT COMMENT '联系人ID',
  `elder_id` bigint NOT NULL COMMENT '所属老人ID',
  `name` varchar(100) NOT NULL COMMENT '联系人姓名',
  `phone` varchar(20) NOT NULL COMMENT '联系电话',
  `email` varchar(100) NULL COMMENT '邮箱',
  `relationship` varchar(50) NULL COMMENT '关系',
  `is_primary` tinyint(1) NOT NULL DEFAULT 0 COMMENT '是否主要联系人',
  `created_at` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  `deleted` tinyint NOT NULL DEFAULT 0 COMMENT '逻辑删除标记',
  PRIMARY KEY (`id`),
  INDEX `idx_contact_elder` (`elder_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 六、关键技术点

1. **呼叫机制：** 使用 `window.location.href = 'tel:电话号码'` 调起手机原生拨号界面
2. **主要联系人：** `isPrimary` 字段标识主要联系人，一键呼叫优先拨打主要联系人
3. **逻辑删除：** 使用 `deleted` 字段实现软删除
4. **CORS：** 后端已配置全局 CORS，前端可直接调用 API
